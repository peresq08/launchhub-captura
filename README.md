# Launch Hub · Captura de OQ

Página para capturar fotos y datos de un OQ desde el teléfono (iPhone o Android).

- Se abre en el navegador; no requiere instalación ni cuenta.
- Solo contiene el código de la página: no incluye datos.
- Lo que se captura se guarda en el propio teléfono hasta que el usuario comparte el archivo de captura.
- La página no envía nada a internet.

Se genera desde el repositorio privado de Launch Hub (`npm run build` → `dist-captura/index.html`). No editar a mano.
